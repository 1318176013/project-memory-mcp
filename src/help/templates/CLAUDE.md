## 项目记忆（project-memory MCP）

开始任何非琐碎的编码任务前（无论是改已有功能，还是新增功能）：

1. 读工作空间根的 `.project-memory`（JSON），取出 `projectId`；读不到则跳过本节。
2. 用该 projectId 调 `search_knowledge(projectId, query)` 查相关的决策 / 约定 / 教训 / 写法。
   - query 按【任务领域 / 模块 / 技术点】组织，而非按"改没改旧文件"判断——纯新增功能同样要守项目约定、也可能撞上记过的坑。
3. 动手前用一句话说明：将遵循哪条已查到的约定 / 避开哪个坑（没查到相关记忆也说一句"无相关记忆"）。

仅一次性、扔了也无所谓的琐碎改动可跳过（改文案、加日志、临时脚本等）。
